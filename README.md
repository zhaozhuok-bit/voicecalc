# 语音计算器 (VoiceCalc)

一个离线可用的中文语音计算器：说「三十二加五十八」就能算，不用联网、不用装第三方语音服务。

> 为什么自带语音引擎：很多手机（ColorOS / EMUI 等无 Google 服务的机型）系统里没有任何 `RecognitionService`，
> 调用系统语音识别必然失败。本项目内置 [Vosk](https://alphacephei.com/vosk/) 中文小模型，离线识别。

## 功能

- 🎤 离线中文语音识别：点底部麦克风说话，停顿后自动结束、自动计算并朗读结果
- 🔢 完整按键计算，支持连续计算（出结果后按数字＝新算；按运算符＝接着算）
- 📜 计算记录：保留最近 30 天，可点击回填
- 🔄 横竖屏自适应：竖屏单键盘，横屏左右手分工（左＝显示+运算，右＝数字+等于+语音）
- ⌨️ 外接键盘（USB / 蓝牙）：数字、四则运算、回车＝等于、退格、Esc＝清空，按键时屏幕同步高亮＋发声
- 🔊 按键人声可开关，设置会记住

## 构建

需要 Linux（arm64/aarch64 也可）和 JDK 17：

```bash
./download-deps.sh   # 拉取 Vosk 引擎、中文模型、Android SDK（约 150MB）
./build.sh           # 输出 build/VoiceCalc.apk
```

依赖说明：

| 依赖 | 用途 | 位置 |
|---|---|---|
| Vosk Android 0.3.47 | 离线语音识别引擎 | `vosk/aar/` |
| JNA 5.13.0 | Vosk 的 JNI 调用层 | `vosk/jna/` |
| vosk-model-small-cn-0.22 | 中文声学模型（42MB） | `assets/model/` |
| Android SDK platform 34 + build-tools 34 | 编译工具 | `sdk/` |

> 模型和 SDK 不进仓库（体积原因），首次构建用 `download-deps.sh` 自动获取。

## 键盘映射

| 物理键 | 作用 |
|---|---|
| `0-9`、小键盘数字 | 数字 |
| `+` `-` `*` `/`（含小键盘） | 加减乘除 |
| `Shift + =` | 加号 |
| `Shift + 8` / `Shift + 5` | 乘号 / 百分号 |
| `Enter` / 小键盘回车 / 小键盘 `=` | 等于 |
| `Backspace` / `Delete` | 退格 |
| `Esc` / `Clear` | 清空 |
