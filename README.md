# 语音计算器 (VoiceCalc)

一个离线可用的中文语音计算器：说「三十二加五十八」就能算，不用联网、不用装第三方语音服务。

> 为什么自带语音引擎：很多手机（ColorOS / EMUI 等无 Google 服务的机型）系统里没有任何 `RecognitionService`，
> 调用系统语音识别必然失败。本项目内置 [Vosk](https://alphacephei.com/vosk/) 中文小模型，离线识别。

## 功能

- 🎤 离线中文语音识别：点底部麦克风说话，停顿后自动结束、自动计算并朗读结果
- 🔢 完整按键计算，支持连续计算（出结果后按数字＝新算；按运算符＝接着算）
- 📜 计算记录：保留最近 30 天，可点击回填
- 🔄 横竖屏自适应：竖屏单键盘，横屏左右手分工（左＝显示+运算，右＝数字+等于+语音）
- ⌨️ 外接键盘（USB / 蓝牙）：数字、四则运算、回车＝等于、退格、Esc＝清空，按键时屏幕同步高亮＋发声
- 🌐 中英文切换（EN / 中）：界面、按键发音、结果朗读、语音输入都跟着换语言
- 🔊 按键人声可开关，设置会记住


## 使用方法

**语音计算**：点底部「🎤 说话算一算」（横屏在右下角），直接说算式，例如
「三十二加五十八」「百分之二十」「十五乘以四」。说完停顿一下，程序会自动结束识别、算出结果并朗读。

支持的中文说法：`零一二三四五六七八九十百千万亿`、`点`、`加 减 乘 除以`、`百分之`、`等于多少`，
也兼容常见同音误识别（热/室 → 十，家 → 加，见/建 → 减，成/城 → 乘，出 → 除）。

**按键计算**：
- 出结果后直接按数字 → 开始一道新题，上一题缩小显示在上方
- 出结果后按 `＋ − × ÷` → 从结果继续算
- 提示行最多保留 4 条历史，最新的一条紧贴当前结果上方，更早的向左排开

**横屏**：左手边是显示屏和运算符（`C` `＋` `−` `×` `÷`），右手边是数字、`=`、语音和退格，单手握着也能按。

**外接键盘**：插 USB 键盘或连蓝牙键盘后，按键会实时映射到屏幕按键，屏幕同步高亮并发出人声。

## 常见问题

**为什么装完有 47MB？**
内置了中文和英文两套离线语音模型（合计约 80MB），所以不联网也能识别，也不会把语音发到任何服务器。

**为什么不用系统自带语音识别？**
国内不少机型（ColorOS、HarmonyOS 等无 Google 服务的系统）根本没有 `RecognitionService`，
调用系统接口必然失败，所以自带引擎。

**识别不准怎么办？**
说慢一点、一次说一个完整算式；或在「关于」里确认人声开关没影响麦克风。四和十这类同音字已通过受限词表优化。

## 构建

需要 Linux（arm64/aarch64 也可）和 JDK 17：

```bash
./download-deps.sh   # 拉取 Vosk 引擎、中文模型、Android SDK（约 150MB）
./build.sh           # 输出 build/VoiceCalc.apk
```

依赖说明：

| 依赖 | 用途 | 位置 |
|---|---|---|
| Vosk Android 0.3.47 | 离线语音识别引擎 | `vosk/aar/` |
| JNA 5.13.0 | Vosk 的 JNI 调用层 | `vosk/jna/` |
| vosk-model-small-cn-0.22 | 中文模型（42MB） | `assets/model/` |
| vosk-model-small-en-us-0.15 | 英文模型（40MB） | `assets/model_en/` |
| Android SDK platform 34 + build-tools 34 | 编译工具 | `sdk/` |

> 模型和 SDK 不进仓库（体积原因），首次构建用 `download-deps.sh` 自动获取。

## 键盘映射

| 物理键 | 作用 |
|---|---|
| `0-9`、小键盘数字 | 数字 |
| `+` `-` `*` `/`（含小键盘） | 加减乘除 |
| `Shift + =` | 加号 |
| `Shift + 8` / `Shift + 5` | 乘号 / 百分号 |
| `Enter` / 小键盘回车 / 小键盘 `=` | 等于 |
| `Backspace` / `Delete` | 退格 |
| `Esc` / `Clear` | 清空 |
